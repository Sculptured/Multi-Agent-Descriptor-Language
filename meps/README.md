# MADL Enhancement Proposals

A MEP proposes a change to what a MADL document can say or means. The process is in
[GOVERNANCE.md](../GOVERNANCE.md); start with an issue using the **MEP** template, then copy
[0000-template.md](0000-template.md) to `NNNN-short-name.md`.
